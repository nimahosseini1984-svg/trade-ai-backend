# Trade AI Backend — Develop Mode

## این چیه؟
سرور Node.js سبک که مستقیم به `cdn.tsetmc.com` وصل می‌شود و قیمت، حجم و اطلاعات نماد را به‌صورت JSON برمی‌گرداند. این نسخه فقط برای **توسعه محلی (develop)** است.

## نصب و اجرا

```
npm install
npm run dev
```

سرور روی `http://localhost:4000` بالا می‌آید.

## Endpoint های موجود

| متد | مسیر | توضیح |
|---|---|---|
| GET | `/` | تست سلامت سرور |
| GET | `/api/search?q=نام یا کد نماد` | جستجوی نماد |
| GET | `/api/identity/:insCode` | اطلاعات هویتی نماد |
| GET | `/api/price/:insCode` | قیمت و حجم لحظه‌ای |
| GET | `/api/history/:insCode?days=30` | تاریخچه قیمت |
| GET | `/api/symbol/:insCode/summary` | ترکیب هویت + قیمت |

## نکته مهم درباره insCode
هر نماد در تسمک یک کد داخلی طولانی (insCode) دارد، نه نام فارسی. برای پیدا کردنش اول از `/api/search?q=...` استفاده کن، insCode را از پاسخ بگیر، بعد در سایر endpoint ها استفاده کن.

مثال جستجوی «فولاد»:
```
http://localhost:4000/api/search?q=فولاد
```

## وضعیت فعلی — رک و صادق
- این نسخه **develop** است، هنوز production نیست (بدون کش، بدون rate-limit، بدون HTTPS، بدون دیتابیس)
- تسمک گاهی هدر/فیلتر جغرافیایی اعمال می‌کند؛ اگر از سرور خارج ایران اجرا کنید ممکن است خطای دسترسی بدهد — این طبیعی و مطابق چیزی است که در سند اولیه پیش‌بینی شده بود
- حقیقی/حقوقی هنوز اضافه نشده — endpoint دقیقش را در فاز بعدی (بعد از تست این نسخه) اضافه می‌کنم، چون فرمت خامش نیاز به پارس بیشتر دارد

## مرحله بعد پیشنهادی
بعد از تست این نسخه روی سیستم شما (و دیدن اینکه از IP شما تسمک جواب می‌دهد یا نه)، اضافه می‌کنیم:
1. endpoint حقیقی/حقوقی (`GetClientTypeData` مشابه)
2. کش ساده حافظه‌ای (in-memory) برای کاهش درخواست به تسمک
3. اتصال این بک‌اند به UI فعلی PWA
